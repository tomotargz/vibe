# MVPの仕様

方針: MVPはできる限り小さくする。ここにない機能はMVPの後で検討する。

## コンセプト
- ToDoとメモを区別せず、すべて「ノート」として扱う
- ノートはタイトルと本文を持ち、状態は「未完了」か「完了」のどちらか
- 本文はコマンドでは入力しない。Markdownファイルをエディタで直接編集して書く

## コマンド
コマンド名は `vibe`。

| コマンド | 動作 |
|---|---|
| `vibe add <タイトル>` | 未完了のノートを追加し、振ったIDを表示する |
| `vibe list` | 完了済みも含めて全件をID順に表示する |
| `vibe done <ID>` | ノートを完了にする |
| `vibe show <ID>` | ノートのタイトル・状態・本文を表示する |

### 使い方の例
```console
$ vibe add 牛乳を買う
added 1
$ vibe add 設計メモ
added 2
$ vibe done 1
$ vibe list
1 [x] 牛乳を買う
2 [ ] 設計メモ
$ vibe show 2
2 [ ] 設計メモ

(本文)
```

## データ
- 保存場所: `$XDG_DATA_HOME/vibe/`(未設定なら `~/.local/share/vibe/`)。場所を変えたいときは `XDG_DATA_HOME` を設定する
- 1ノートにつき1ファイル。ファイル名は `<ID>.md`
- IDは1から始まる連番。追加するたびに、既存の最大ID+1を振る
- front matterには `title` と `done` だけを書く。IDはファイル名から取る

```markdown
---
title: 牛乳を買う
done: false
---

(本文。エディタで直接書く)
```

## エラー
- 存在しないIDを指定したら、エラーメッセージを表示して終了コード1で終わる
- 引数の数が合わないときは、Cobraの標準の使い方表示に任せる

## MVPに含めないもの
- 編集・削除・未完了に戻すコマンド(ファイルを直接編集・削除すればよい)
- 一覧の絞り込みや並べ替え
- 作成日時などの追加の項目
- 独自の環境変数や設定ファイル
